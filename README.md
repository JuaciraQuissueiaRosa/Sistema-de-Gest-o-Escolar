School Management - Grades and Performance System

This project aims to manage students' grades and performance on a school management platform. Developed in .NET 8 with Windows Forms, the system allows students to be registered, grades to be assigned and performance reports to be generated, as well as graphs showing the averages for each class.

Main features:
	- Student and Class Registration: Simple interface for adding new students and assigning them to a specific class.
	- Grade Management: Possibility of adding and editing grades per student and per subject.
	- Performance Reports: Display of graphs and averages to analyse student performance.

Technologies used:
	- .NET 8: Framework used to develop the application.
	- Windows Forms: Graphical interface based on the traditional desktop application model.
	- LINQ: Used to perform queries and efficient manipulation of data in lists.
	- Graphs: Generated based on grade averages, facilitating visual analysis of school performance.
	- Local files: Data is stored in files in the system itself, ensuring persistence of information between sessions.
 
Relevant features:
	- The use of LINQ enables fast and effective queries, simplifying data manipulation and report creation.
	- The interface remains fluid and responsive, even when processing large volumes of information.

- Data is stored locally, allowing information to be kept between uses of the application.
